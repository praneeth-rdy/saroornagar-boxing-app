# App architecture (fe)

The module map of the Flutter app. Whoever adds, removes or renames a file, provider or route
updates the matching row in the same change.

## State (2026-11-05)

Foundation (run 1 task-06): config, Supabase bootstrap, error mapping, theme A tokens, widget
kit, router skeleton with one placeholder route, test support and the proofs harness. Run 2
task-01 adds the Today tab (sessions and attendance marking); task-02 the Trainees tab (list, add, edit,
status, photo, history); task-03 Trials (public booking form, booked screen, staff Trials tab); task-04 Fees and reports (record payment, fee history on the trainee, fee status and monthly attendance under More); task-05 Staff admin (list, add, edit, reset password, block, admins only, under More). Dependencies: flutter_riverpod 3.4.3, go_router 18.1.3, supabase_flutter
2.18.3, intl 0.20.3, image_picker 1.2.4, shared_preferences 2.5.6, freezed_annotation 3.1.0, json_annotation 4.12.0; dev build_runner
2.17.1, freezed 4.0.3, json_serializable 6.15.2. Inter 4.1 (OFL) bundled under
`assets/fonts/`.

## Build

| Item | Where | Notes |
|---|---|---|
| Release signing | `android/app/build.gradle.kts` (`signingConfigs.release`) | Reads `android/key.properties` (`storePassword`, `keyPassword`, `keyAlias=upload`, `storeFile=keystore/upload-keystore.jks`, relative to `android/`); keystore at `android/keystore/upload-keystore.jks`. Both gitignored, passwords in `creds.md`. Without `key.properties` a release build is debug-signed and Gradle warns (visible only with `flutter build -v`). Certificate `CN=Saroornagar Boxing Club`. |
| Network permission | `android/app/src/main/AndroidManifest.xml` | `INTERNET` declared in the main manifest so release builds reach Supabase (the template grants it only in debug and profile). |
| App name | `android/app/src/main/AndroidManifest.xml` | Boxing Club (`android:label` in the main manifest). |
